# TL01-P2 — Static Asset and Profile Budget Contract

This slice checks **source image header metadata** only. It does not decode/import images through Godot, measure GPU resource usage, certify device performance or change the TL00 exported-runtime gate.

## Observations

- PNG IHDR, JPEG SOF and WebP VP8X/VP8/VP8L dimensions are read from the source file headers.
- The inspector reads at most **256 KiB** of each file. A JPEG whose dimension markers are beyond this window is UNKNOWN, not PASS.
- Traversal is sorted, ignores Godot-generated/cache directories, and does not follow symlinks.
- Each Web/Android target independently compares the observed width and height against its configured `profiles[profile].textureMax` value.
- Source file length is recorded as `sourceBytes` and is **not** an estimate of GPU memory, mip levels, compression efficiency, texture bandwidth, draw calls or runtime FPS.

## Rules

| Rule | Severity | Trigger |
| --- | --- | --- |
| PF201 | warning | A measured source width or height exceeds a target's `textureMax` |
| PF202 | warning | A recognized source file has an unreadable or malformed header |
| PF203 | error | A target's `textureMax` is missing or not a positive integer |
| PF204 | info | Dimensions cannot be concluded for an unsupported format or bounded header |

P0/P1 rule identities and severities remain stable. Any unsupported raster/vector formats (SVG, TGA, DDS, KTX2, EXR, HDR, AVIF, etc.) are explicitly UNKNOWN instead of silently counted as within budget.

## Machine-readable evidence

`doctor --json` includes an `assetBudget` object with schema `talarion.asset-budget/v1`, scope `source-header-only`, per-source file format/dimensions/unknown reason, and separate target results.

`dimensionStatus` is one of: `within-declared-source-limit`, `over-budget`, `unknown`, `invalid-profile`. **Empty asset sets and any unknown dimensions never produce a source-size PASS**. A source-size PASS still does not mean the asset imports or runs correctly.

`performance.status` is always `not-measured`. `targetFps` and `drawCallBudget` are declared numbers only; `measuredFps` and `measuredDrawCalls` remain null. Both `hardwareCertified` and `performanceCertified` remain false.
