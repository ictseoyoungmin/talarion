# TL02-P3 — Reproducible Performance Review

TL02-P3 closes the TL02 **evidence and reporting** milestone. It does **not** certify physical Android devices or assert FPS compliance from one CI run.

## Commands

On a single exported Web+Android replay, run TL02-P0 authority first, then:

```bash
node bin/talarion.mjs budget report current artifacts/parity/performance-authority.json artifacts/parity/performance-review --json
```

The outputs are `performance-review.json` (`talarion.performance-review/v1`) and standalone, escaped `performance-review.html`. CI runs this mode on **actual** downloaded Web/Android evidence. It checks the proof chain and requires `decision: evidence-only`, one candidate and no baseline per target. CI success is evidence completeness, **not** a regression or FPS PASS.

For archived independent runs, use:

```bash
node bin/talarion.mjs budget report evidence/cohorts.json artifacts/performance-review --json
```

The input is a `talarion.performance-cohorts/v1` manifest. Example:

```json
{
  "schema": "talarion.performance-cohorts/v1",
  "policy": { "maxFpsDropPct": 10, "maxProcessRisePct": 20 },
  "cohorts": {
    "web": { "baseline": [], "candidate": [
      { "runId": "gha-132-web-1", "environmentKey": "web-ci-runner-class-a",
        "file": "web-run-132/performance-authority.json", "sha256": "<actual 64 hex checksum>" }
    ] },
    "android": { "baseline": [], "candidate": [
      { "runId": "gha-132-android-1", "environmentKey": "android-emulator-api30-x86",
        "file": "android-run-132/performance-authority.json", "sha256": "<actual 64 hex checksum>" }
    ] }
  }
}
```

`sha256` is the *actual* SHA-256 of the referenced authority JSON bytes. The files and manifest remain within the checked-out repository; symlink escape and out-of-root destinations are refused. For an actual multi-run decision, each target needs at least three independent baseline and three independent candidate evidence objects, each with distinct run ID, distinct authority-file SHA-256 and distinct raw sample SHA-256. Identical runtime class, declared profile, replay fingerprint, sampled tick window, and an explicit environment key are mandatory. One file copied to three paths cannot count as three runs. Run IDs and environment labels come from trusted orchestration, not from the user-supplied file itself; content hashing guards accidental modification, **not** malicious fabrication of an entire cohort.

## Decision matrix

| Report decision | Meaning | CLI exit |
| --- | --- | --- |
| `evidence-only` | Valid but insufficient independent comparison (default CI) | 0 |
| `observational-no-degradation` | Valid baseline+candidate cohorts show no observed regression within declared noise/threshold logic | 0 |
| `review-inconclusive` | Variation overlaps threshold; needs investigation | 0 (review required) |
| `blocked-observational-degradation` | Independent cohorts conclusively cross a configured relative regression or declared budget threshold | 1 |
| `invalid-evidence` | Corrupt, duplicated, nonmatching or otherwise invalid evidence | 1 |

Per-target reports distinguish `insufficient-evidence`, `observational-no-degradation`, `observed-degradation`, `inconclusive`, and `invalid-evidence`. Four budget metrics show statuses such as `not-declared`, `insufficient-independent-runs`, `unobserved-or-inconsistent`, `observed-within-limit`, `observed-below-limit`, `observed-above-limit` and `inconclusive-noise`—none is device certification. Process P95 and engine memory bytes are engine-observed metrics, **not** total GPU frame time or GPU residency; draw-call counts are unavailable. Noise fences are MAD engineering heuristics, not p-values or confidence intervals. Relative regressions from P2 and declared budget observations are separately displayed.

The JSON includes source authority SHA-256, raw sample SHA-256, cohort labels, environment tags and counts. HTML escapes all user-supplied strings. Output bytes are deterministic for a fixed manifest and evidence. Existing TL00 15/15 state, strict 3/3 spatial images and 9/9 acceptance gates remain unchanged.

## Release boundary

Even on a report labelled `observational-no-degradation`, `hardwareCertified` and `performanceCertified` remain false. Physical-device FPS, thermal and lifecycle qualification is a distinct [Release Certification](release-certification.md) process. The intermittent interaction screenshot issue [#4](https://github.com/ictseoyoungmin/talarion/issues/4) remains OPEN. The single-run CI path intentionally cannot promote its observations to multi-run performance signoff.
