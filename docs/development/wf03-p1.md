## Objective

The API36 signed Android App Bundle itself is only a distribution package. This slice proves that the separately extracted **Release APK**, not the earlier WF02 Debug APK, runs the original Signal Garden Three.js game inside Android WebView and preserves authoritative gameplay under Replay, real ADB-driven UI input and Activity lifecycle events.

## Pipeline

1. Independently verify P0 signed AAB, version and original source/vendor/host provenance; fail if modified or missing.
2. Require a single authorized **emulator** (ro.kernel.qemu == 1) before any potentially destructive package replacement. No physical-device uninstall is authorized.
3. Rebuild universal APK from that AAB with pinned bundletool and external upload credentials. Independently inspect Android package name, versionCode=2, versionName=0.2.0, targetSdk=36, actual original asset and DEX files, APK v2+ signature and signer certificate fingerprint identical to the signed AAB.
4. On that exact SHA-256-pinned Release APK, collect 10+ independent fixed-tick state snapshots, three Android PNG checkpoints, telemetry and final VICTORY from actual WebView runtime.
5. On the **same** Release APK, perform three real ADB UI taps and HOME → Activity.pause/WebView hidden → Activity.resume/WebView visible → input-after-resume, proving retained authoritative position/beacon state and no hidden page reload. Preserve five raw Android PNG screenshots.
6. Compare independent WF01 Playwright original-browser replay against extracted Release APK replay using existing WP001–WP007, including 3/3 named PNGs, exact state equivalence and observed 1/2/3 HUD segments. No pixel-identity claim.
7. Record three independent authorities: AAB build/verification, Release APK runtime/interactive, browser↔Release WebView parity. Only after all three, plus legacy Godot and WF02 CI, pass on the exact PR head may this reference/emulator slice close.

CLI: `node bin/talarion.mjs web-native android release test examples/web-native --json` **requires** the previously built exact-source signed AAB. It does not generate a Debug APK, silently change source, upload keys or publish to Google Play.

## Non-goals and safety

CI signs with a **disposable external key**, used only in the current job; no production key ownership or Play App Signing enrollment evidence exists. The whole test is emulator-only: it never authorizes package removal from a physical device. It does not prove Android process-death restore, screen rotation, physical-device performance/compatibility, Play target-policy sufficiency, device catalog, app review or publication. These belong to WF03-P2 and independent release-certification work.

Inspect `artifacts/build/android-webview-release/install-evidence.json`, `artifacts/run/android-webview-release`, `artifacts/run/android-webview-release-interactive`, and `artifacts/parity/wf03/release-webview-parity.json` for machine-observed proof. Store uploaded CI evidence only; do not upload keystore/password or disposable AAB as a misleading production artifact.
